### 2. EXIT INTENT POPUP - Лідогенерація при виході
**Статус:** ❌ ВІДСУТНІЙ - БЛОКУЄ КОНВЕРСІЇ!

**Функціональність:**
- **Trigger:** `mouseleave` event коли курсор йде до верхньої частини
- **Умова:** `e.clientY <= 0` (курсор покидає вікно зверху)
- **One-time показ:** localStorage flag щоб не показувати повторно
- **Форма:** Ім'я + телефон + повідомлення
- **Інтеграція:** Відправка через send_telegram.php

**JavaScript логіка:**
```javascript
let exitIntentTriggered = false;

document.addEventListener('mouseleave', (e) => {
    if (e.clientY <= 0 && !exitIntentTriggered) {
        showExitPopup();
        exitIntentTriggered = true;
    }
});
```

**КРИТИЧНІСТЬ:** Без цього втрачається 20-30% потенційних лідів!
